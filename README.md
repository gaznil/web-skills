# web-skills

A hand-picked collection of Claude Code skills, gathered from open-source repositories. Every skill here carries an open-source licence (MIT, ISC or Apache-2.0). I did not write most of them: **all credit belongs to the original authors**, and each skill keeps its own licence terms (see the LICENSE file or the `license` line in its SKILL.md).

## Install

Copy the skill folders you want into `~/.claude/skills/` (Windows: `C:\Users\<you>\.claude\skills\`) and restart Claude Code.
